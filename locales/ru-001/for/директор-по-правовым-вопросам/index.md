## Значения по умолчанию, которые не являются законом

Несколько настроек — это значения по умолчанию, а не юридическая консультация: срок уведомления об уходе, срок решения и обжалования по гибкому графику и причины отказа. Руководство по развёртыванию требует **подтвердить их** для вашей юрисдикции. Законодательные расчёты, например налог на зарплату, не реализованы.

## Решения, которые принимаете вы

Правовое основание для каждой цели обработки, оценка воздействия на защиту данных и её подписание, соглашения с обработчиками, график хранения, который вы примете, и включать ли какую-либо функцию особых категорий.

См. также [директора по персоналу](../директор-по-персоналу/index.md) и [директора по рискам](../директор-по-рискам/index.md).
