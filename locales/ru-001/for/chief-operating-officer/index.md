# Для операционного директора (COO)

**Вопрос, который вы, вероятно, задаёте:** есть ли у нас нужные люди в нужном месте в нужное время и что ломается, если кто-то отсутствует?

## Что вы получаете

| Вы хотите знать | Где отвечает WPM | Читать |
| --- | --- | --- |
| Может ли команда покрыть отсутствие | Замены для каждого человека, график дежурств с обменами и напоминаниями и вид замещения, который прямо говорит, когда никого нет | [people-directory-and-cover.md](../../../../spec/people-directory-and-cover.md) |
| Время, посещаемость и отпуска | Записи времени, заявки на отпуск с маршрутом согласования, накопления и смены | [workforce-management.md](../../../../spec/workforce-management.md) |
| Соблюдаются ли пределы рабочего времени | Рекомендательные ограждения рабочего времени; они предупреждают и не блокируют | WPM-R27, тот же файл |
| Мощность по навыкам, месяц за месяцем | Пулы навыков, предложение и потребность программ, обязательства партнёров, пул-ограничение и проверка старта, являющаяся рекомендацией, с записанными решениями о старте | [delivery-capacity.md](../../../../spec/delivery-capacity.md) |

## Как читать вид мощности

Мощность планируется по пулу навыков, а не по человеку. Каждый месяц пула даёт один из четырёх результатов, а необъявленный навык — это *неизвестно*, а не нехватка. Проверка старта — рекомендация, а решение начать фиксирует человек. Планирование по критической цепи и критическому пути здесь не ведётся: оно относится к project-portfolio-management.

## Ограничения

- У доли непостоянных работников пока нет тренда: нужны снимки численности, разбитые по основанию (WPM-T139, не построено).
- «Пул» в виде непостоянных работников — это подразделение, пока планы не определят пулы.
- Планирование смен и расчёты налога на зарплату не заменяют ваши системы графиков или расчёта зарплаты.
- Несколько видов загружают записи организации в память; цифр нагрузки не измеряли ([readiness-assessment.md](../../../../spec/readiness-assessment.md), пробел 8).

См. также [директора по персоналу](../chief-people-officer/index.md) и [генерального директора](../chief-executive-officer/index.md).

## Насколько это актуально

Написано 2026-10-11 по спецификации, а не по запуску программы для этой страницы.
