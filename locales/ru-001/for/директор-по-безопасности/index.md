# Для директора по безопасности

**Вопрос, который вы, вероятно, задаёте:** как это защищено, как мы узнаем, что на него напали или им злоупотребили, и что никто не проверял?

## Что вы получаете

| Вопрос | Что есть | Читать |
| --- | --- | --- |
| Угрозы | Модель угроз: активы, действующие лица, границы доверия, средство контроля как построено и то, что **не оценивалось** | [governance/threat-model.md](../../../../spec/governance/threat-model.md) |
| Аутентификация | Вход включён по умолчанию; промышленная среда отказывается запускаться, если он выключен или нет источника ключей токенов; вход через корпоративный каталог (OIDC) | [production-readiness.md](../../../../spec/production-readiness.md), [operations/entra-sign-in.md](../../../../spec/operations/entra-sign-in.md) |
| Авторизация | Политика решает только по действию; классифицированная таблица решает, кому нужно знать, на каждом маршруте чтения, а тест сканирования исходников падает на неклассифицированном маршруте | [auth.md](../../../../spec/auth.md) |
| Аудит | Журнал только на добавление, связанный хешами, с конечной точкой проверки; записи не несут текста причины и значения | [audit.md](../../../../spec/audit.md) |
| Транспорт и браузер | Заголовки безопасности в каждом ответе API, явный список разрешённых источников CORS, не дающий запуститься, если он не задан, `no-store` на `/api` | WPM-R73 в [production-readiness.md](../../../../spec/production-readiness.md) |
| Злоупотребление | Ограничения частоты на вызывающего, строже для стирания, импорта, экспорта и маршрутов токенов | WPM-R74, тот же файл |
| Небезопасная конфигурация | Запуск отвергает незашифрованное соединение с базой данных или Redis на другой хост и отсутствующий источник CORS | [operations/deployment.md](../../../../spec/operations/deployment.md) |
| Данные в покое | Шифрованные резервные копии; общий кэш хранит только неличные запросы и при сбое открыт | [operations/backup-and-restore.md](../../../../spec/operations/backup-and-restore.md) |
| Цепочка поставок | Проверки лицензий и запретов через `cargo deny`, включённые общие крейты, перечень компонентов ПО при выпуске | [production-readiness.md](../../../../spec/production-readiness.md) |
| Инциденты | Рабочая инструкция с первыми действиями; контакты и обязанности по уведомлению добавляете вы | [operations/runbook.md](../../../../spec/operations/runbook.md) |
| Самооценка | Чек-лист средств контроля: выполнено, выполнено частично, не выполнено, отвечает внедряющая сторона | [governance/assessment-checklist.md](../../../../spec/governance/assessment-checklist.md) |

## Известные пробелы, как они записаны

- Независимое тестирование на проникновение не проводилось. Тесты написал автор.
- Actions закреплены по тегу, а не по хешу, и образы не подписаны.
- Ограничения частоты действуют на каждый экземпляр.
- Приложение использует ту роль базы данных, которую ему дали; набор ролей с минимальными правами не предоставляется.
- Отзыв токенов и их максимальный срок — дело вашего поставщика идентификации.
- Путь менеджера контента загружает скрипт с публичной CDN без закреплённой версии и без хеша целостности.
- Журналы не проверялись на персональные данные, а журнал аудита не выгружается в систему мониторинга.
- Управляемый Redis (кластер, sentinel, пользователи с управлением доступом) не пробовали.

## Что могут сделать только люди

Заказать независимое тестирование на проникновение, проверить модель угроз для вашей среды, провести учения по восстановлению на вашей платформе и настроить защиту веток на платформе хостинга. См. [оценку готовности](../../../../spec/readiness-assessment.md), вывод которой — **не готов** для развёртывания с высокими требованиями к надёжности.

См. также страницы [директора по рискам](../директор-по-рискам/index.md) и [директора по информации](../директор-по-информации/index.md).

## Насколько это актуально

Написано 2026-10-11 по спецификации, а не по запуску программы для этой страницы. Числа, которые меняются (тесты, миграции, выполненные задачи), здесь не копируются; читайте их в [implementation-status.md](../../../../spec/implementation-status.md), который создаёт скрипт. WPM — демонстрационное программное обеспечение с синтетическими данными: эта страница говорит, что оно делает и чего не делает, и не утверждает, что оно подходит вашей организации. Ничто здесь не является юридической консультацией.
