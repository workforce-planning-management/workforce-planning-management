# Для директора по рискам (CRO)

**Вопрос, который вы, вероятно, задаёте:** что может пойти не так с этой системой, что этому мешает и что никто не проверял?

## Честная отправная точка

[Оценка готовности](../../../../spec/readiness-assessment.md) от 2026-10-11 выносит вывод **не готов** для развёртывания с высокими требованиями к надёжности. Она нашла одно блокирующее препятствие, проверяя работающую службу: любой вошедший пользователь мог прочитать больничный коллеги и его причину в свободном тексте. Это исправлено и проверено. Рубежи, которые могут закрыть только люди, всё ещё открыты.

## Открытые риски, как они записаны

Закрепление и подписание цепочки поставок, свидетельства нагрузки, проверки журналов на персональные данные, общие ограничения частоты между экземплярами, набор ролей базы данных с минимальными правами и указания по отзыву токенов — открытые пункты оценки готовности, к каждому есть задача. Тесты написал автор; ни один не является независимой проверкой.

## Что могут сделать только люди

Независимое тестирование на проникновение, независимый аудит доступности, подписанная оценка воздействия внедряющей стороны, учения по восстановлению на вашей платформе и утверждение оценок воздействия на равенство. Репозиторий объявляет их рубежами и не отмечает выполненными.

См. также [директора по информации](../chief-information-officer/index.md) и [директора по правовым вопросам](../chief-legal-officer/index.md).

## Насколько это актуально

Написано 2026-10-11 по спецификации, а не по запуску программы для этой страницы. Числа, которые меняются (тесты, миграции, выполненные задачи), здесь не копируются; читайте их в [implementation-status.md](../../../../spec/implementation-status.md), который создаёт скрипт. WPM — демонстрационное программное обеспечение с синтетическими данными: эта страница говорит, что оно делает и чего не делает, и не утверждает, что оно подходит вашей организации. Ничто здесь не является юридической консультацией.
