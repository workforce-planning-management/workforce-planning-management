# Управление, риски, соответствие

**Вопросы, которые вы, вероятно, задаёте:** кто за что отвечает, что может пойти не так и что этому мешает, и какие доказательства я могу показать оценщику? Эта страница собирает материалы по управлению, рискам и соответствию в одном месте. Страницы [директора по рискам](../директор-по-рискам/index.md) и [директора по правовым вопросам](../директор-по-правовым-вопросам/index.md) охватывают то же поле по ролям.

## Риски: что может пойти не так

| Тема | Что есть | Читать |
| --- | --- | --- |
| Вывод | **Не готов** для развёртывания с высокими требованиями к надёжности; одно блокирующее препятствие найдено проверкой (чтение не следовало принципу «доступ по необходимости») и исправлено | [readiness-assessment.md](../../../../spec/readiness-assessment.md) |
| Угрозы | Модель угроз: активы, действующие лица, границы, средство контроля как построено и то, что **не оценивалось** | [governance/threat-model.md](../../../../spec/governance/threat-model.md) |
| Свидетельство подделки | Журнал аудита только на добавление, связанный хешами, с конечной точкой проверки; записи не содержат текста причины или значения | [audit.md](../../../../spec/audit.md) |
| Безопасный отказ при запуске | Промышленная среда отказывается запускаться при выключенном входе, без ключей токенов, при незашифрованном соединении с базой данных на другой хост или при незашифрованном удалённом Redis | [production-readiness.md](../../../../spec/production-readiness.md) |
| Восстановление | Шифрованные резервные копии, учения по восстановлению, запускаемые в CI, журнал стирания, чтобы восстановление не вернуло стёртого человека | [operations/backup-and-restore.md](../../../../spec/operations/backup-and-restore.md) |
| Инциденты | Рабочая инструкция с первыми действиями; контакты и пути эскалации добавляет внедряющая сторона | [operations/runbook.md](../../../../spec/operations/runbook.md) |
| Предвзятость в оценках | Шаблон воздействия на равенство и реестр каждой оценки, у каждой — черновик оценки | [equality-impact/register.md](../../../../spec/equality-impact/register.md) |
| Открытые риски | Закрепление и подписание цепочки поставок, свидетельства нагрузки, проверки журналов на персональные данные, общие ограничения частоты, набор ролей базы данных с минимальными правами, указания по отзыву токенов | [readiness-assessment.md](../../../../spec/readiness-assessment.md), раздел 3 |

## Что могут сделать только люди

Это рубежи, а не код, и репозиторий не отмечает их выполненными: независимое тестирование на проникновение, независимый аудит доступности, ваша оценка воздействия на защиту данных, подписанная вашим ответственным лицом, учения по восстановлению на вашей платформе, профессиональная проверка переводов и ваше утверждение оценок воздействия на равенство.

## Ограничения этой страницы

Таблицы указывают на документы. Верен ли каждый документ для вашего развёртывания, судить вам и вашему оценщику. Тесты автора не являются независимой проверкой, и ничто здесь не является юридической консультацией или сертификацией.

## Насколько это актуально

Написано 2026-10-11 по спецификации, а не по запуску программы для этой страницы.
