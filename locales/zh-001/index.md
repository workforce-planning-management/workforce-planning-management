# 劳动力规划管理

**覆盖员工从入职到退休全生命周期的开源人力资源平台。**

劳动力规划管理（Workforce Planning Management，WPM）将招聘、考勤与休假、员工发展、劳动力规划和薪资整合在一个应用中。它是演示软件，用于评估和作为参考设计。

> **演示软件。** WPM 不是生产环境的人力资源或薪资系统。它只使用合成数据，其法定计算仅作示例。请勿录入真实的个人数据。参见[监管立场](../../spec/regulatory.md)（英文）。

[运行演示](start/index.md) [角色文档](for/index.md) [GitHub 上的源代码](https://github.com/workforce-planning-management/workforce-planning-management)

## 优势

人力资源数据通常分散在不同工具中，例如申请人收件箱、休假电子表格和排班白板。工具之间的每次传递都会增加人工工作和出错风险。WPM 的设计目标是减少这类传递。

- **单一系统。** 入职、休假、培训和薪资记录保存在一个应用中，减少重复录入。
- **数据最小化。** 不应保存的数据没有对应字段，不应披露的数据没有对应的 API 路由。例如，系统没有诊断字段，脉搏调查的答复也没有作者。
- **报告规则。** 未知值不报告为零，汇总数据不识别个人，估算值说明其依据。
- **本地化。** 应用提供 17 个语言区域，角色文档提供 21 个，包括从右到左的语言。各国特定规则以数据形式保存。译文由人工智能生成，未经母语人士审校。
- **可追溯性。** 源代码开放，每项行为都可追溯到有编号的需求、设计决策和任务。
- **独立部署。** 技术栈为 Rust JSON API、SvelteKit 客户端和 PostgreSQL。可从全新克隆构建，与同系列应用的集成是可选的。

## 功能

- **招聘与档案。** 职位申请、候选人流程、入职、员工档案和组织架构图。
- **考勤与排班。** 考勤与休假、带工时检查的排班、支持换班和提醒的值班表，以及员工名录。
- **员工发展。** 绩效评估、360 度反馈、学习、技能差距分析、培训时间建议和必修学习。
- **规划与报告。** 战略劳动力规划、指标与洞察，以及首席执行官仪表板。
- **入职与离职。** 带日期的清单，以及带审计记录的最后一天交接。
- **内部沟通。** 带受众、链接和阅读统计的公告。
- **员工权利与健康。** 健康提示、匿名脉搏调查、合理调整、数据主体访问、删除和保留。
- **薪资。** 薪资和薪酬管理，法定计算仅作示例。

## 比较

下表将 WPM 与三类人力资源系统进行比较。这是一般性参考，不是基准测试。另见[按产品比较](../../docs/compare/index.md)（英文）。

| | WPM | 一体化套件（Workday、SAP SuccessFactors、BambooHR） | 开源人力资源（frappe/hrms、OrangeHRM、Horilla、Odoo HR） | 单点工具（Greenhouse、Lever、Gusto、ADP） |
| --- | --- | --- | --- | --- |
| **范围** | 全生命周期，从入职到退休 | 范围相近，在同一平台上 | 相同的核心功能 | 单一功能 |
| **许可** | 开源 | 商业 | 开源 | 商业 |
| **适合生产使用** | 否 | 是 | 是 | 是 |
| **主要优势** | 数据最小化、可追溯设计、技能差距与培训时间分析 | 集成且有支持的单一平台 | 更多的集成、本地化和部署 | 单一功能的深度 |
| **典型适用情况** | 评估、参考设计或进一步开发 | 需要有支持的系统的组织 | 希望在生产环境使用开源软件的组织 | 需要单一功能深度且能集成其余部分的组织 |
