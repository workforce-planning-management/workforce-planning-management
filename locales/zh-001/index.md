# 劳动力规划管理

**员工从入职到退休的一切，尽在一处。**

欢迎！劳动力规划管理（Workforce Planning Management，WPM）是一个开源人力资源平台，把招聘、考勤与休假、员工发展、规划和薪酬整合在一起，让信息不再散落于收件箱和电子表格之间。它是一个可以运行、阅读和学习的实际演示。

> ⚠️ **演示软件。** WPM 不是用于生产环境的人力资源或薪资系统：它只使用合成数据，其法定计算仅作示例。请勿在其中使用真实的个人数据。参见[监管立场](../../spec/regulatory.md)（英文）。

[开始引导教程](start/index.md) [了解它对您的角色意味着什么](for/index.md) [在 GitHub 上查看代码](https://github.com/workforce-planning-management/workforce-planning-management)

## 为什么选择 WPM

申请人记录在收件箱里，休假记录在电子表格里，排班写在白板上：每一次在这些孤岛之间交接都会丢失信息。WPM 基于不同的思路构建。

- **一个系统，而不是六个。** 员工全生命周期集中在一起，新员工的入职、休假、培训和薪酬无需重复录入。
- **隐私内建于设计。** 不应存储的内容没有对应的字段，不应披露的内容没有对应的接口。系统中没有诊断字段，匿名调查的答复也没有作者。
- **值得信赖的数字。** 未知值绝不显示为零，汇总数据不点名任何人，每项估算都说明其依据。
- **面向全世界。** 应用支持 17 个语言区域，这些角色文档支持 21 个，包括从右到左的语言；各国不同的规则是数据，而不是代码。译文由人工智能撰写，尚未经母语人士审校。
- **开放且可追溯。** 它是开源的，每项行为都可追溯到有编号的需求、设计决策和任务。
- **可独立运行。** 由 Rust JSON API、SvelteKit 客户端和 PostgreSQL 组成。从全新克隆即可构建和运行，与同系列应用的连接是可选的。

## 它能做什么

- 🤝 **招聘与档案。** 职位申请、候选人流程、入职、员工档案和组织架构图。
- 🗓️ **日常工作。** 考勤与休假、带工时保护的排班、支持换班和提醒的值班表，以及员工名录。
- 🌱 **员工发展。** 绩效评估、360 度反馈、学习、技能差距分析、培训时间建议和必修学习。
- 📊 **领导决策。** 战略劳动力规划、指标与洞察，以及可在一块 iPad 屏幕上看完的首席执行官仪表板。
- 👋 **入职与离职。** 带日期的清单，以及带审计记录的最后一天交接。
- 📣 **内部沟通。** 带受众、链接和阅读统计的公告。
- 💚 **权利与健康。** 健康提示、匿名调查、合理调整、数据主体访问、删除和保留。
- 💳 **薪酬。** 薪资和薪酬管理，法定计算仅作示例。

## 如何比较

这只是一份方向指引，不是排名：下面每类系统都适合某些人。[将 WPM 与各产品逐一比较](../../docs/compare/index.md)（英文）。

| | WPM | 一体化套件（Workday、SAP SuccessFactors、BambooHR） | 开源人力资源（frappe/hrms、OrangeHRM、Horilla、Odoo HR） | 单点工具（Greenhouse、Lever、Gusto、ADP） |
| --- | --- | --- | --- | --- |
| **覆盖范围** | 从入职到退休的全生命周期 | 范围相近，在同一平台上 | 相同的核心功能 | 专注一个领域，并做到出色 |
| **来源** | 开源 | 商业 | 开源 | 商业 |
| **现在能用于真实的人力资源工作吗？** | 不能：这是演示 | 能 | 能 | 能 |
| **突出之处** | 隐私内建于设计、可追溯的设计、技能差距与培训时间 | 一个集成且有支持的平台 | 集成、本地化和部署都多得多 | 在单项工作上的深度 |
| **适合何时选择** | 您想评估、学习或基于开放的设计进行构建 | 您现在就需要有支持的系统 | 您现在就想在生产环境中使用开源软件 | 某项工作需要深度，且您能连接其余部分 |
