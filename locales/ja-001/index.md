# ワークフォース・プランニング・マネジメント

**採用から退職まで、従業員のライフサイクル全体を扱うオープンソースの人事プラットフォーム。**

ワークフォース・プランニング・マネジメント(WPM)は、採用、勤怠と休暇、人材育成、要員計画、給与を一つのアプリケーションにまとめます。デモ用ソフトウェアであり、評価と参照設計を目的としています。

言語: العربية, বাংলা, Cymraeg, English, Español, हिन्दी, 日本語, 한국어, Русский, اردو, 中文

> **デモ用ソフトウェアであり、本番利用の準備はまだ整っていません。** WPM は合成データのみを使用し、法定計算は例示です。実在の個人データは入力しないでください。[本番への道筋](path-to-production/index.md)では、本番利用に何が必要で、各部分がどの程度整っているかを説明しています。[規制上の立場](../../spec/regulatory.md)もご覧ください。

## 利点

人事データは、応募者の受信箱、休暇の表計算シート、当番表のボードなど、別々のツールに分散していることがよくあります。ツール間で移すたびに手作業が増え、誤りのリスクが高まります。WPM はこうした移し替えを減らすように設計されています。

- **単一のシステム。** 入社手続き、休暇、研修、給与の記録を一つのアプリケーションで保持するため、再入力が減ります。
- **データ最小化。** 保持すべきでないデータにはフィールドがなく、開示すべきでないデータには API ルートがありません。たとえば診断名のフィールドはなく、パルスサーベイの回答には回答者の情報がありません。
- **報告のルール。** 不明な値をゼロとして報告せず、集計から個人を特定できないようにし、推計にはその根拠を明記します。
- **ローカライズ。** アプリケーションは 25 のロケール、役割別ブリーフは 21 のロケールで利用でき、右から左に書く言語も含まれます。国ごとの規則はデータとして保持されます。翻訳は AI が作成したもので、ネイティブスピーカーによる確認は受けていません。
- **追跡可能性。** ソースコードは公開されており、各動作は番号付きの要件、設計判断、タスクにたどれます。
- **独立した展開。** 構成は Rust の JSON API、SvelteKit のクライアント、PostgreSQL です。新規クローンからビルドでき、姉妹アプリケーションとの連携は任意です。

## 機能

- **採用と記録。** 要員要求、応募者パイプライン、入社手続き、従業員記録、組織図。
- **勤怠とスケジュール。** 勤怠と休暇、労働時間チェック付きのシフト、交代とリマインダー付きのオンコール当番表、社員名簿。
- **育成。** 評価、360 度フィードバック、学習、スキルギャップ分析、研修時間の推奨、必須学習。
- **計画と報告。** 戦略的要員計画、指標とインサイト、CEO ダッシュボード。
- **入社者と退職者。** 日付付きのチェックリストと、監査証跡付きの最終日の引き継ぎ。
- **コミュニケーション。** 対象者、リンク、既読数を備えたお知らせ。
- **従業員の権利と健康。** ウェルビーイングの問いかけ、匿名のパルスサーベイ、合理的配慮、本人開示、消去、保持。
- **給与。** 給与計算と報酬。法定計算は例示です。

## 比較

この表は WPM を三種類の人事システムと比較したものです。大まかな目安であり、ベンチマークではありません。[製品別の比較](../../docs/compare/index.md)もご覧ください。

| | WPM | オールインワン型スイート(Workday、SAP SuccessFactors、BambooHR) | オープンソースの人事(frappe/hrms、OrangeHRM、Horilla、Odoo HR) | 単機能ツール(Greenhouse、Lever、Gusto、ADP) |
| --- | --- | --- | --- | --- |
| **対象範囲** | 採用から退職までの全ライフサイクル | 一つのプラットフォームで同様の範囲 | 同じ中核機能 | 一つの機能 |
| **ライセンス** | オープンソース | 商用 | オープンソース | 商用 |
| **主な強み** | データ最小化、追跡可能な設計、スキルギャップと研修時間の分析 | 統合され、サポートされた単一のプラットフォーム | 連携、ローカライズ、展開実績が多い | 一つの機能に深い |
| **向いている用途** | 評価、参照設計、またはさらなる開発 | サポートされたシステムを必要とする組織 | 本番でオープンソースを使いたい組織 | 一つの機能に深さが必要で、残りは自前で連携できる組織 |

## ヘルプを得るには

- **不具合の報告や質問**は、[課題トラッカー](https://github.com/workforce-planning-management/workforce-planning-management/issues)にお寄せください。ページ、行ったこと、期待したこと、実際に起きたことを書いてください。実在の個人データは含めないでください。
- **セキュリティ上の問題**は、公開の課題ではなく、[セキュリティポリシー](../../SECURITY.md)に従ってメールで報告してください。
- **アプリケーション内でタスクを学ぶ。** アプリケーションのヘッダーにある**ヘルプ**リンクから、ヘルプページと、従業員、管理者、人事向けの手順ガイドを開けます。各エラーメッセージからもそこへリンクしています。
