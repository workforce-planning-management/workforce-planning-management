# 隐私声明

本声明说明 Workforce Planning Management（WPM）网站和 WPM 应用在您的浏览器中保存什么、为什么保存、保存多久，以及如何删除。网站是 <https://workforce-planning-management.github.io/>；应用是 WPM 演示软件，无论它在何处运行。（更新于 2026-11-17，WPM-R253。）

二者都没有分析统计、广告，也没有第三方脚本、字体或图片。二者在您的浏览器中保存的任何内容都不会被用来跨网站追踪您。

## 网站

网站是一组静态页面。它没有登录，也没有表单。它保存的内容都在您自己的浏览器中：

| 内容 | 保存位置 | 名称 | 保存的内容 | 原因 |
| --- | --- | --- | --- | --- |
| 您的主题 | 您的浏览器的本地存储 | `mxi.wpm.theme` | 主题名称，例如 `dark` | 让下一页和您下次访问时呈现您选择的样子 |
| 您的主题 | 仅用于本网站的 Cookie | `wpm-theme` | 主题名称，例如 `dark` | 即使您的浏览器保留 Cookie 却清除了本地存储，或者反过来，主题也能恢复 |
| 您的文字大小 | 您的浏览器的本地存储 | `mxi.wpm.text-size` | 大小名称，例如 `large` | 让下一页和您下次访问时使用您选择的文字大小 |
| 您的语言 | 不保存任何内容 | | | 语言是每个页面地址的一部分（例如 `/cy-001/`），因此无需记住任何内容 |
| 您在页面上的位置 | 您的浏览器的会话存储，仅限此标签页 | `sveltekit:history-info`、`sveltekit:navigation-snapshot`、`sveltekit:snapshot` | 滚动位置，以及您在此标签页中打开页面的顺序 | 让“后退”和“前进”把您带回原来的位置。这些由构建网站所用的框架（SvelteKit）保存 |

您作出选择之前，不保存任何选择。在您选择之前，网站跟随您的浏览器的浅色或深色设置及其常规文字大小，不保存主题或文字大小。您在选择栏中作出选择时，选择即被保存；再次选择会替换它。您在页面之间移动时，会话存储会被写入。

网站的其他部分不保存任何内容：

- **搜索**在您的浏览器中运行，使用网站发布的索引，不保存任何内容。您输入的词会放入页面地址（`?q=`），以便分享结果页面；当该地址从网站托管方加载时（重新加载时，或打开分享的链接时），托管方会随请求收到它，如同收到任何地址一样。
- 走向生产使用之路页面上的**就绪程度滑块**不保存任何内容，重新加载会恢复作者的估计。
- **分享**只在您选择时才打开您选择的网站（电子邮件、LinkedIn、Reddit、Bluesky 或 Mastodon）。此后适用该网站自己的隐私声明。

## WPM 应用

应用保存同样类型的选择，以及让您保持登录的 Cookie：

| 内容 | 保存位置 | 名称 | 保存的内容 | 原因 |
| --- | --- | --- | --- | --- |
| 您的主题 | 您的浏览器的本地存储 | `mxi.wpm.theme` | 主题名称 | 让每个页面呈现您选择的样子 |
| 您的文字大小 | 您的浏览器的本地存储 | `mxi.wpm.text-size` | 大小名称 | 让每个页面使用您选择的文字大小 |
| 您的语言 | 您的浏览器的本地存储 | `mxi.wpm.locale` | 您最后打开的页面的语言代码，例如 `cy-001` | 让不带语言的地址以您的语言打开 |
| 您的语言 | 仅用于应用的 Cookie | `wpm-locale` | 同一语言代码 | 让服务器能把不带语言的地址转到您的语言 |
| 您的登录 | 仅用于应用的 Cookie，页面脚本无法读取 | `__Host-mxi_session`（在开发者自己的计算机上为 `mxi_session`） | 代表您的登录会话的随机数 | 让您在页面之间保持登录；没有它，您每打开一页都要重新登录 |
| 内容编辑器的语言 | 您的浏览器的本地存储，仅当您打开内容编辑器（`/admin`）时 | `sveltia-cms.prefs` | 编辑器的设置，其中包括它的语言 | 让编辑器以应用的语言打开 |
| 您在页面上的位置 | 您的浏览器的会话存储，仅限此标签页 | `sveltekit:history-info`、`sveltekit:navigation-snapshot`、`sveltekit:snapshot` | 滚动位置，以及您在此标签页中打开页面的顺序 | 让“后退”和“前进”把您带回原来的位置 |

与网站不同，应用一显示主题和文字大小就会保存它们，即使您还没有选择；它也会保存您打开的每个页面的语言。项目改名之前的键（`mxi.hcm.theme`、`mxi.hcm.locale`）会被移到上面的名称下并删除。

登录 Cookie 是唯一代表您的项目。其中的随机数本身没有任何含义：它指向的登录会话由应用的服务器保存，退出登录即结束该会话。应用对其记录中的人保存哪些内容，见下文倒数第二节。

## 谁会收到

本地存储和会话存储从不离开您的浏览器。

Cookie 会随您的浏览器向设置它的网站发出的每个请求一起发送，不会发送给其他任何网站（`SameSite=Lax`，通过 HTTPS 时还有 `Secure`）：

- 网站的 `wpm-theme` Cookie 发送给托管网站的 GitHub Pages。项目的任何程序都不读取它。
- 应用的 `wpm-locale` Cookie 和登录 Cookie 发送给运行应用的服务器，服务器读取它们来选择您的语言，并确认您已登录。

托管网站的 GitHub 会收到您的浏览器发出的请求，任何网站托管方都是如此。[GitHub 的隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)说明它记录哪些内容。运行应用的组织决定其服务器记录哪些内容。

## 保存多久

- 网站的 `wpm-theme` Cookie：自您最后一次选择主题起 400 个日历日，这是浏览器保存 Cookie 的最长期限。
- 应用的 `wpm-locale` Cookie：自您最后一次打开页面起 365 个日历日。
- 登录 Cookie：直到您退出登录或关闭浏览器。
- 本地存储：直到您清除它。
- 会话存储：直到您关闭标签页。

## 如何删除

在浏览器设置中清除该网站的数据（Cookie 和网站数据），可针对网站、应用或两者。之后网站会像首次访问时一样运行；应用会要求您重新登录。退出应用登录会删除登录 Cookie。

## 为什么没有同意横幅

每一项的保存都是为了向您提供您所要求的服务：按您的设置呈现网站或应用，使用您的语言，并在应用中保持登录。英国和欧盟关于 Cookie 的规则（英国《隐私与电子通信条例》和欧盟《电子隐私指令》）将这类存储视为严格必要的存储，无需征得同意。这是本项目对这些规则的理解，不是法律意见。

## 应用保存的记录

本声明涵盖保存在您的浏览器中的内容。应用还在其服务器上保存关于人员（员工、应聘者及其联系人）的记录。运行应用的一方对这些记录负责，并为记录中的人撰写隐私声明（[评估检查清单](../../../spec/governance/assessment-checklist.md)，英文，第 3.10 题）。演示软件只保存合成数据。
