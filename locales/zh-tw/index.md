# 勞動力規劃管理

**覆蓋員工從入職到退休全生命週期的開源人力資源平台。**

勞動力規劃管理（Workforce Planning Management，WPM）將招聘、考勤與休假、員工發展、勞動力規劃和薪資整合在一個應用中。它是演示軟體，用於評估和作為參考設計。

> **演示軟體，尚未準備好用於生產。** [走向生產使用之路](path-to-production/index.md)說明生產使用需要什麼，以及每一部分的就緒程度。它只使用合成資料，其法定計算僅作示例。請勿錄入真實的個人資料。參見[監管立場](../../spec/regulatory.md)（英文）。

## 優勢

人力資源資料通常分散在不同工具中，例如申請人收件箱、休假電子表格和排班白板。工具之間的每次傳遞都會增加人工工作和出錯風險。WPM 的設計目標是減少這類傳遞。

- **單一系統。** 入職、休假、培訓和薪資記錄儲存在一個應用中，減少重複錄入。
- **資料最小化。** 不應儲存的資料沒有對應欄位，不應披露的資料沒有對應的 API 路由。例如，系統沒有診斷欄位，脈搏調查的答覆也沒有作者。
- **報告規則。** 未知值不報告為零，彙總資料不識別個人，估算值說明其依據。
- **本地化。** 應用提供 17 個語言區域，角色文件提供 21 個，包括從右到左的語言。各國特定規則以資料形式儲存。譯文由人工智慧生成，未經母語人士審校。
- **可追溯性。** 原始碼開放，每項行為都可追溯到有編號的需求、設計決策和任務。
- **獨立部署。** 技術棧為 Rust JSON API、SvelteKit 客戶端和 PostgreSQL。可從全新複製構建，與同系列應用的整合是可選的。

## 功能

- **招聘與檔案。** 職位申請、候選人流程、入職、員工檔案和組織架構圖。
- **考勤與排班。** 考勤與休假、帶工時檢查的排班、支援換班和提醒的值班表，以及員工名錄。
- **員工發展。** 績效評估、360 度回饋、學習、技能差距分析、培訓時間建議和必修學習。
- **規劃與報告。** 戰略勞動力規劃、指標與洞察，以及執行長儀表板。
- **入職與離職。** 帶日期的清單，以及帶審計記錄的最後一天交接。
- **內部溝通。** 帶受眾、連結和閱讀統計的公告。
- **員工權利與健康。** 健康提示、匿名脈搏調查、合理調整、資料主體訪問、刪除和保留。
- **薪資。** 薪資和薪酬管理，法定計算僅作示例。

## 比較

下表將 WPM 與三類人力資源系統進行比較。這是一般性參考，不是基準測試。另見[按產品比較](../../docs/compare/index.md)（英文）。

| | WPM | 一體化套件（Workday、SAP SuccessFactors、BambooHR） | 開源人力資源（frappe/hrms、OrangeHRM、Horilla、Odoo HR） | 單點工具（Greenhouse、Lever、Gusto、ADP） |
| --- | --- | --- | --- | --- |
| **範圍** | 全生命週期，從入職到退休 | 範圍相近，在同一平台上 | 相同的核心功能 | 單一功能 |
| **許可** | 開源 | 商業 | 開源 | 商業 |
| **適合生產使用** | 否 | 是 | 是 | 是 |
| **主要優勢** | 資料最小化、可追溯設計、技能差距與培訓時間分析 | 整合且有支援的單一平台 | 更多的整合、本地化和部署 | 單一功能的深度 |
| **典型適用情況** | 評估、參考設計或進一步開發 | 需要有支援的系統的組織 | 希望在生產環境使用開源軟體的組織 | 需要單一功能深度且能整合其餘部分的組織 |
